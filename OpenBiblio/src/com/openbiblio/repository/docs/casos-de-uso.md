# Casos de uso

## Añadir libro

1. El usuario abre la aplicación.
2. Selecciona la opción para añadir libro.
3. Introduce título, autor, ISBN, género y estado de lectura.
4. Guarda el registro.
5. El libro queda almacenado en SQLite.

## Buscar libro

1. El usuario introduce un criterio de búsqueda.
2. La aplicación filtra por título, autor, género o ISBN.
3. Se muestran los resultados.

## Editar libro

1. El usuario selecciona un libro.
2. Modifica los datos.
3. Guarda los cambios.

## Eliminar libro

1. El usuario selecciona un libro.
2. Confirma la eliminación.
3. El registro se elimina de la base de datos.

## Consultar recomendaciones

1. La aplicación analiza los libros registrados.
2. Se muestran recomendaciones relacionadas.
