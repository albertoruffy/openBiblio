# Guía de instalación

## Requisitos

- Java JDK 8 o superior
- JavaFX
- Git
- Eclipse o NetBeans
- SQLite

## Clonar el repositorio

git clone https://github.com/albertoruffy/openBiblio.git

## Abrir el proyecto

1. Abrir Eclipse o NetBeans.
2. Seleccionar “Open Project” o “Import Project”.
3. Elegir la carpeta del repositorio.
4. Esperar a que carguen las librerías.

## Ejecutar

Ejecutar la clase:

com.openbiblio.app.MainApp

## Base de datos

La aplicación usa SQLite y los archivos:

- openbiblio.db
- bibliografía abierta.db
