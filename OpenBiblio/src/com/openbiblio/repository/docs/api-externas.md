# APIs externas

## Open Library API

OpenBiblio integra la API pública de Open Library para enriquecer la información bibliográfica.

### Funcionalidades

* Búsqueda por ISBN.
* Recuperación automática de metadatos.
* Consulta de autores.
* Consulta de títulos.

### Ventajas

* Reduce la introducción manual de datos.
* Mejora la calidad de la información almacenada.
* Permite completar fichas bibliográficas automáticamente.

### Servicio responsable

OpenLibraryService.java
