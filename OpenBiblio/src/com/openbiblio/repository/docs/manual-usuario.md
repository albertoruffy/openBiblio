# Manual de usuario

## Pantalla principal

Al iniciar OpenBiblio se muestra la pantalla principal de gestión de la biblioteca.

### Menú lateral

#### Biblioteca

Permite visualizar todos los libros almacenados.

#### Añadir libro

Abre el formulario de creación de un nuevo libro.

#### Exportar biblioteca

Genera una copia exportable de la colección de libros.

#### Importar biblioteca

Permite cargar libros desde un archivo CSV.

#### Backup Online

Genera una copia de seguridad remota mediante FTP.

#### Restaurar Backup

Recupera una copia de seguridad almacenada previamente.

---

## Búsqueda de libros

El cuadro de búsqueda permite localizar libros mediante:

* Título
* Autor
* ISBN

Los resultados se actualizan automáticamente.

---

## Gestión de libros

Cada libro puede:

* Consultarse.
* Modificarse.
* Eliminarse.
* Cambiar su estado de lectura.
* Incorporar notas personales.

---

## Recomendaciones

La aplicación dispone de un sistema de recomendaciones basado en la colección personal del usuario.

Mediante el botón "Refrescar" se generan nuevas recomendaciones.
